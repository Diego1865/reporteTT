El diagrama de clases representa la estructura estática del sistema, mostrando las principales entidades, sus atributos y las relaciones entre ellas. Se observa una jerarquía de herencia donde la clase \textit{Usuario} es la base para los actores \textit{Tutor} y \textit{Alumno}. Asimismo, se modelan los elementos centrales del sistema como \textit{Ejercicio}, \textit{Intento} y \textit{Resultado}, los cuales permiten gestionar el proceso de captura, análisis y retroalimentación de la escritura. Finalmente, se integran los módulos de procesamiento \textit{AnalisisOCR} y \textit{EvaluacionCLS}, responsables de la conversión de imágenes a texto y del cálculo del puntaje ortográfico mediante la secuencia correcta de letras, respectivamente. La clase \textit{Resultado} conserva las secuencias correctas obtenidas y posibles, la calificación y si el tutor ya confirmó el puntaje.

Con el propósito de representar el comportamiento dinámico del sistema, en la Figura~\ref{fig:diagrama_secuencia} se presenta el diagrama de secuencia correspondiente al proceso de análisis de ejercicios, el cual describe la interacción entre los diferentes componentes involucrados desde la captura de la imagen hasta la generación de resultados.

\begin{figure}[H]
    \centering
    \resizebox{\textwidth}{!}{%
    \begin{sequencediagram}
        \def\unitfactor{0.9}
        \newinst{al}{:ALUMNO}

        \newinst[0.9]{db}{:BASE\_DE\_DATOS}
        \begin{call}{al}{Subir\_imagen}{fe}{Mostrar\_retroalimentación}
            \begin{call}{fe}{Enviar\_imagen}{be}{Enviar\_resultados}
                \begin{call}{be}{Procesar\_imagen}{ocr}{Texto\_extraído}
                \end{call}
                \begin{call}{be}{Calcular\_CLS}{cls}{Puntaje\_CLS}
                \end{call}
                \begin{call}{be}{Guardar\_resultado}{db}{Confirmación}
                \end{call}
            \end{call}

    \caption{Diagrama de secuencia del procesamiento de ejercicios}
    \label{fig:diagrama_secuencia}
\end{figure}

El diagrama muestra cómo el alumno interactúa con la interfaz para enviar una imagen, la cual es procesada por el backend mediante un módulo OCR para la extracción de texto. Posteriormente, el módulo de evaluación ortográfica compara el texto con las respuestas aceptadas del ejercicio y calcula el puntaje CLS. Finalmente, los resultados son almacenados en la base de datos y enviados al usuario para su visualización.

\subsection{Diagrama de componentes del sistema}

Con el objetivo de representar la estructura modular del sistema, en la Figura~\ref{fig:diagrama_componentes} se presenta el diagrama de componentes, el cual muestra la organización de los principales elementos de software y sus interacciones dentro de la arquitectura de la aplicación.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\textwidth]{Imagenes/DiagramaDeComponentes.png}
    \caption{Diagrama de componentes del sistema}
    \label{fig:diagrama_componentes}
\end{figure}

El diagrama muestra la separación del sistema en tres capas principales: cliente, servidor y persistencia. El frontend se encarga de la interacción con el usuario, mientras que el backend gestiona la lógica del sistema y coordina el reconocimiento OCR y la evaluación ortográfica mediante CLS. Finalmente, la base de datos permite almacenar la información generada y consultada durante la operación del sistema.

La separación entre el reconocimiento OCR y la evaluación ortográfica permite una arquitectura más flexible y escalable, ya que cada componente puede ser optimizado o actualizado de manera independiente. Además, esta división facilita el mantenimiento del sistema y mejora la eficiencia en el procesamiento de la información.

\begin{figure}[H]
    \centering
    \resizebox{\textwidth}{!}{%
    \begin{tikzpicture}[

El diagrama muestra la organización del sistema en distintos nodos físicos, incluyendo el dispositivo del usuario, el servidor de aplicaciones, el servidor de procesamiento y el servidor de base de datos. En el dispositivo del usuario se ejecuta el navegador web, desde donde se realizan las solicitudes al backend mediante los protocolos HTTP y Protocolo Seguro de Transferencia de Hipertexto (\textit{Hypertext Transfer Protocol Secure}, HTTPS por sus siglas en inglés). El servidor de aplicaciones gestiona la lógica del sistema, mientras que el servidor de procesamiento aloja el servicio OCR, que se comunica con Google Cloud Vision, y la evaluación ortográfica mediante CLS. Finalmente, el servidor de base de datos permite almacenar y consultar la información generada durante la operación del sistema.

Esta figura representa una distribución conceptual de responsabilidades. En la implementación actual, el reconocimiento OCR se delega al servicio externo Google Cloud Vision; el Back-End realiza la validación, el cálculo del puntaje CLS y la persistencia. El futuro cálculo de métricas del trazo corresponde al procesamiento local de imagen y todavía no está implementado.
