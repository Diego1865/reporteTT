\subsection{Factibilidad}
 
El estudio de factibilidad es un instrumento que sirve para orientar la toma de decisiones en la evaluación de un proyecto. Se formula con base en información que tiene la menor incertidumbre posible para medir las posibilidades de éxito o fracaso, apoyándose en él se tomará la decisión de proceder o no con su implementación.
 
% ─────────────────────────────────────────────
\subsubsection{Factibilidad Técnica}
% ─────────────────────────────────────────────
 
La factibilidad técnica estudia la posibilidad tecnológica para que el proyecto pueda llevarse a cabo satisfactoriamente con el menor riesgo posible. Las herramientas tecnológicas se dividen en software y hardware.
 
\paragraph{Software y entornos de ejecución}

El desarrollo local utiliza React/Next.js para la interfaz, FastAPI para el servidor y SQL Server para la persistencia. El presupuesto considera el uso de las herramientas de la Tabla~\ref{tab:software} sin gasto incremental de licencias para el equipo. Los servicios de nube y el reconocimiento OCR se presupuestan por separado, según su consumo.

La configuración local y la de demostración son independientes. La demo definida en el repositorio utiliza una máquina virtual de Compute Engine con Caddy, Next.js y FastAPI. Caddy publica los puertos web y dirige las solicitudes hacia la interfaz o la API. La base de datos se aloja en Cloud SQL para SQL Server mediante una dirección privada. Google Cloud Vision realiza el reconocimiento fuera de la máquina virtual.

La configuración preparada considera una VM e2-medium con 2 vCPU compartidas, 4 GB de memoria, disco balanced de 40 GB e IPv4 fija en \texttt{us-central1-a}. Para Cloud SQL se especifica SQL Server 2022 Express, 1 vCPU, 3.75 GB de memoria y SSD inicial de 10 GB con crecimiento automático, en una sola zona. Estos datos describen los archivos de despliegue; la existencia y el consumo de los recursos deben comprobarse en la cuenta de nube.

La operación prevista incluye siete respaldos diarios retenidos en Cloud SQL y exportaciones a Cloud Storage con una retención de 30 días. Su costo debe incorporarse al presupuesto junto con el almacenamiento de las imágenes. La configuración de respaldos requiere comprobarse mediante un ensayo de restauración. Al depender de una sola VM y una instancia zonal, la demo no ofrece alta disponibilidad.
